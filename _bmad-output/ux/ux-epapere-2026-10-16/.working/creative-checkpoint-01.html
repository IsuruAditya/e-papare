02 — Typography
Font Pairing
Inter for English UI (clean, highly legible at small sizes, widely used in SaaS). Noto Sans Sinhala for Sinhala script (comprehensive Unicode coverage, consistent rendering on Android budget devices, Google Fonts). Both use the same type scale — no separate scale per language.
Architecture confirmed (AD-28): Noto Sans Sinhala self-hosted subset U+0D80–U+0DFF, font-display: swap, served from same origin. Fallback: Noto Sans → system-ui. Sinhala line-height is 1.7–1.8 (glyph height requires more vertical space than Latin).
