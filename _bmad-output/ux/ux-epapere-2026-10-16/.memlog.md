- (event) UX workflow started. Sources confirmed: PRD (prd.md + addendum.md, final 2026-10-16), Master Requirements (master-requirements.md, v1.0.0). No prior UX runs found. Fresh Create mode.
- (decision) Change request incorporated before Discovery begins: (1) Mandatory bilingual UI — English (en) + Sinhala (si-LK) across all five roles, all journeys, all screens. (2) Mandatory Light Mode and Dark Mode with semantic design tokens. (3) Four-way matrix required: English+Light, English+Dark, Sinhala+Light, Sinhala+Dark. (4) Language switcher on login, registration, and all authenticated dashboards. (5) Theme switcher accessible from all screens. (6) Language and theme persist across sessions. (7) Switching language must not lose form data. (8) Light Mode is the default unless superseded by institute decision. (9) User-generated free text is NOT auto-translated. (10) Institute-configured content shows available language with untranslated indicator when only one language exists.
- (decision) Brand colors confirmed: White #FFFFFF (primary surface) + Brand Blue #3E3A98 (primary action/brand). These two are locked and non-negotiable. Complementary palette to be derived from these. Dark Mode must NOT be a simple color inversion — develop proper dark surfaces. Semantic design tokens required throughout.
- (decision) Design direction confirmed: modern professional Education SaaS / Student Information System aesthetic. Clean, premium, consistent. Explicit avoidance list: childish design, excessive gradients, random bright colors, decorative dashboards, unnecessary animations, inconsistent components, excessive shadows, overcomplicated navigation. Working mode: Fast Path with Creative Tool Checkpoints.
- (decision) Student dashboard priority order confirmed: (1) Join Today's Class (2) My Courses (3) Upcoming Classes (4) Study Materials (5) Class Recordings (6) Monthly Payments (7) Notifications (8) Help and Support. Modern cards, clear course states, prominent primary actions.
- (decision) Architecture spine read (v2, 2026-10-16). Key UX-binding decisions confirmed: AD-6 react-i18next v15, AD-7 feature-organised translation files, AD-8 stable machine-readable backend error codes, AD-9 Tailwind darkMode:class + React ThemeContext, AD-10 CSS custom properties as semantic design tokens, AD-18 TanStack Query v5, AD-19 React Hook Form + Zod, AD-28 Noto Sans Sinhala self-hosted subset U+0D80-U+0DFF font-display:swap. Design system tokens go in src/styles/tokens.css under :root (light) and .dark. No raw Tailwind palette literals for semantic slots.
